📖 Gesture Guide

  • Index Finger Only: Draw
  • 2 Fingers: Select Red
  • 3 Fingers: Select Green
  • 4 Fingers: Select Blue
  • Thumb-Index Pinch: Undo
  • Closed Fist (hold 1.5s): Clear Canvas
  • Open Palm (5 fingers): Hover (no drawing)
